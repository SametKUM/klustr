# Integration previews

These previews render the application's resource detail components with sample data. They document the EC2NodeClass and Flux image automation interfaces without including a real cluster's configuration.

- [EC2NodeClass](karpenter-ec2nodeclass.png): resolved infrastructure, AMI requirements and readiness conditions in the default dark theme.
- [ImageUpdateAutomation](flux-image-automation.png): a cross-namespace Git source, update path, branches and last-push commit in the default light theme.

The sample images complement the live-cluster validation and the integration navigation tests.
